# 本地视觉与 OCR 审核基准

最近复核：2026-08-11。

## 项目决策

- 本地第一层固定使用 **RapidOCR 3.9.2 / PP-OCRv6**，负责印刷中文、普通数字和图中短标签的快速提取。
- **PP-FormulaNet_plus-M** 仅用于已经精确裁出的单个公式，并且输出仍需视觉确认；不得信任整页或自动生成的大块混合区域结果。
- Qwen2.5-VL、InternVL2 和 DeepSeek-OCR-2 均不得自动批准题库题目。图形关系、手写、复杂公式或 OCR 冲突转交远端视觉模型复核。
- 判题继续使用尺寸受控的图片直接交给远端视觉模型；本地大模型只保留诊断用途。

## 小样本受控结果

本报告用于选择项目默认路径，不是通用学术基准。样本覆盖纯印刷标签、函数图像、离散图像、拍照公式和复杂空间向量图文页。

| 引擎 | 样本 | 速度 | 可安全直接使用 | 主要问题 |
|---|---:|---:|---:|---|
| RapidOCR / PP-OCRv6 | 6 页 | 11.7 秒总计，约 2.0 秒/页 | 2 页完整可用，2 页标签部分可用 | 不理解图形关系；复杂公式和手写较弱，但未主动编造题意 |
| Qwen2.5-VL-7B-Instruct 4bit | 6 页 | 加载 29.8 秒；平均 17.2 秒/页 | 1/6 内容可用；0/6 满足严格 JSON 合同 | 重复标签、截断、无效 JSON、编造函数关系和公式 |
| Qwen2.5-VL-7B-Instruct-OCR 4bit | 6 页 | 加载 29.3 秒；平均 10.2 秒/页 | 1/6 内容可用；0/6 满足严格 JSON 合同 | 比基础版快，但仍重复、截断、误读公式并编造坐标关系 |
| DeepSeek-OCR-2 BF16（768，无切片） | 4 页 | 加载 13.6 秒；平均 8.7 秒/页 | 1/4 | 纯文字页准确；其余将图像编成数表、圆方程或无关几何证明题 |
| InternVL2-8B 4bit（同日既有基准） | 4 页 | 平均 85.5 秒/页 | 0/4 可无人值守使用 | 极慢；公式、选项和判定均出现严重幻觉 |
| PP-FormulaNet_plus-M | 16 个自动裁剪 | 初始化 6.3 秒；推理 43.6 秒 | 0/16 可无人值守；约 3 个仅作局部线索 | 紧裁剪纯公式偶有帮助；混合文字、手写、图形会生成长伪公式 |

## 权威路由

1. DOCX/可提取文本：直接走结构化文本审核，不调用视觉模型。
2. 图片或扫描页：RapidOCR 先提取印刷文字和标签。
3. 单个疑难公式：只有获得紧裁剪区域后才显式调用 PP-FormulaNet，结果只是候选。
4. 图形关系、手写步骤、复杂排版、OCR 冲突：使用远端视觉模型查看尺寸受控预览。
5. 任一本地模型输出都不得单独把题目置为 `verified`，仍须通过 `audit-item → verify-item` 正式记录。
